# 수협 차량 운행기록

강사 휴대폰 한 대로 실제 GPS 운행을 기록합니다.

1. 휴대폰 브라우저에서 https://hosang78.github.io/gps/ 에 접속합니다.
2. 차량을 선택하고 **운행 시작**을 누른 뒤 브라우저 위치 권한을 허용합니다.
3. 휴대폰에서 처음 받은 유효 위치에 지도가 열립니다. 이후 5초마다 새로운 위치가 있는지 확인합니다.
4. **운행 종료**를 누르면 기기 브라우저에 운행일지가 저장됩니다. 일지를 누르면 경로와 출발·도착점을 확인할 수 있습니다.
5. 차량을 고르고 **마지막 주차 위치**를 누르면 해당 차량에서 운행 종료 전에 수신한 마지막 GPS 위치가 표시됩니다.
6. 운행일지의 **오늘 / 이번 달** 집계는 이 기기에 저장된 GPS 운행의 시작 시각을 기준으로 횟수·거리·시간을 합산합니다.
7. 정확도 30m 이내의 GPS 기록이 30m 반경 안에서 5분 이상 이어지면 지도와 운행일지에 **장시간 정차**로 표시합니다. 15초를 넘는 위치 수신 공백은 정차 시간에서 제외합니다. 카카오 키를 설정하면 확인된 정차 좌표를 카카오에 조회해 건물명이나 주소를 표시합니다.
8. 저장된 운행일지를 열면 출발·도착, 출발 기준 10분 지점, 주요 정차, GPS 기록 공백이 시간순으로 표시됩니다. 이력과 지도 핀을 눌러 위치를 확인하고, **가장 긴 정차 보기** 또는 **전체 경로**를 선택할 수 있습니다.
9. 운행 중에는 화면 꺼짐 방지를 요청합니다. 화면을 잠그거나 다른 앱으로 나가면 브라우저가 GPS 기록을 멈추므로 운행 중에는 화면을 켜 두세요.
10. 운행일지의 **삭제**는 이 기기의 기록만 지웁니다. 서버로 보내지 못한 기록은 **서버 전송 대기 N건**으로 표시되고, 오래된 기록부터 순서대로 전송합니다.
11. 카카오 키가 있으면 저장된 운행의 출발·도착 위치와 마지막 주차 위치에도 건물명이나 주소를 표시합니다.
12. 저장된 운행의 경로는 속도별 색(30 미만 · 30~60 · 60~과속 기준 · 과속)으로 그리고, 과속 기준(기본 80km/h, 설정에서 변경) 이상으로 5초 넘게 달린 구간을 **과속 구간**으로 타임라인과 지도에 표시합니다. 속도는 정확도 30m 이내 GPS 기록의 앞뒤 위치로 계산합니다.
13. 타임라인의 **경로 재생**을 누르면 차량이 경로를 따라 10~120배속으로 움직이며 시각과 속도를 보여줍니다. GPS 기록 공백은 건너뜁니다.
14. 지도 위에서 위아래로 쓸면 화면이 스크롤됩니다. 지도를 직접 이동하거나 확대하려면 지도 위의 **지도 조작**을 켜고, 다시 누르면 화면 스크롤로 돌아옵니다.

카카오맵은 설정에 기존 JavaScript 키를 넣어 사용합니다. 지도 설정의 **서버 기록 연결**은 선택 사항입니다. 접근 코드를 입력하면 서버에 있는 기록을 조회하고 새 기록을 30초 단위로 서버에도 보냅니다. 휴대폰과 PC에 같은 코드를 넣으면 같은 기록을 볼 수 있고, 코드는 그 기기 브라우저에 저장됩니다. 코드 없이 기록한 최근 7일 이내 운행은 운행일지의 **서버로 보내기**로 올릴 수 있습니다. 지도 키와 접근 코드는 소스 파일에 포함하지 않습니다.

## 배포 및 API

- GitHub Pages 배포 경로는 `main` 브랜치의 `/docs`입니다.
- `api/schema.sql`의 테이블은 Neon 프로젝트 sh의 fleet-demo 브랜치, fleet_demo 데이터베이스 전용입니다.
- `api/index.mjs`는 @neondatabase/serverless를 포함해 Node.js 24 대상 ESM으로 번들링한 뒤 index.mjs 이름으로 ZIP에 담아 Neon Function으로 배포합니다.
- 서버 환경 변수 FLEET_DATABASE_URL에는 제한된 DB 계정의 연결 문자열을, FLEET_CODE_HASHES에는 접근 코드의 SHA-256 해시를 쉼표로 구분해 넣습니다.
- 나중에 추가하는 접근 코드는 FLEET_EXTRA_CODE_HASHES에 넣습니다(서버에서 owner-N으로 구분). 배포할 때 `--env`로 넘긴 변수만 바뀌고 나머지는 유지되므로, 기존 FLEET_CODE_HASHES를 다시 입력할 필요가 없습니다.
- `/trips` 응답에는 운행별 이동 거리(`distance_km`, 15초 넘는 GPS 공백 제외)가 포함됩니다.
- `docs/config.js`에는 공개 API URL만 저장합니다.
- 앱은 `/start`와 `/end`에 실제 출발·종료 시각(ms)을 함께 보내고, 서버는 최근 7일 이내 값만 받습니다. 같은 차량에서 13시간 넘게 열려 있는 내 운행은 새 운행 시작 시 자동으로 종료 처리합니다.
